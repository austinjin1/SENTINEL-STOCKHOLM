# Novelty re-check: SENTINEL-Sim model (LSTM with fixed GPP/ER/K600 metabolism head), 2026-11-08

**Claim checked (sim_protocol.md §3.1).**
- A multi-site daily LSTM outputs only T statistics, GPP ≥ 0, ER ≤ 0, K600 > 0 (Raymond-prior-scaled), SC and
  turbidity.
- DO comes **only** through a fixed, differentiable one-station O2 mass balance: Benson–Krause DOsat and
  Schmidt-scaled K, integrated exactly per hour.
- It is trained on continuous USGS DO and T sensors for multi-site hindcasting.
- This extends sim_model_2026-10-25.md.

**Method caveat.** Searches used the agent's general web index (WebSearch/WebFetch), not Scholar, Scopus or WoS.
Forward citations of Sadler et al. 2024 and Rahmani et al. 2023 were *approximated* by topical queries, not run
as true citation queries. Wiley and ScienceDirect full texts were not readable (403).
